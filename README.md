# PullDex

A Pokémon TCG Living Pokédex tracker.

The goal of PullDex is to help collectors complete a Living Dex using only Pokémon cards obtained from sealed products.

## Current Status

🚧 Early Development

## Tech Stack

Backend:
- Python
- FastAPI
- SQLModel
- SQLite

Frontend:
- React
- TypeScript

## Development
