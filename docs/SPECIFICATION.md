# PullDex

## Vision

PullDex is a collection manager designed for Pokémon TCG collectors building a physical Living Pokédex using only cards they have personally pulled from booster packs.

The app tracks:

- Pokémon owned
- Individual cards owned
- Pack opening history
- Missing Pokémon
- Statistics
- Booster pack recommendations

The goal is to recommend which Pokémon TCG booster packs give the highest chance of adding new Pokémon to the user's Living Dex.

---

## Core Rules

1. A Pokémon counts as owned if at least one card featuring that Pokémon has been pulled.

2. Cards bought as singles do not count.

3. Promo cards can count if the user chooses.

4. Multiple copies of a Pokémon do not increase Living Dex progress.

5. Every pulled card should remain in the history forever.

6. The recommendation engine should always favour sets with the highest expected number of new Pokémon.
